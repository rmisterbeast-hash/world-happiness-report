# Проектные прототипы всех шести страниц

В каталоге сохранён полный комплект из **18 отдельных векторных wireframe-прототипов** (не скриншоты): для каждой HTML-страницы адаптивные схемы при 320, 768 и 1280 px.

Прототип отражает последовательность секций, состав первого экрана, карточек, инфографики и завершающих переходов. Фоновые оттенки, контурные блоки и подписанные места компонентов повторяют принципы дизайн-концепции. Он не предназначен для демонстрации итогового рендеринга конкретного браузера. Реальные 18 скриншотов сайта находятся в соседнем каталоге `docs/screenshots/`.
