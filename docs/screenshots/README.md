# Документальные скриншоты сайта

Снимки автоматически получены в GitHub Actions в реальном Chromium при запуске собственного статического сайта через локальный HTTP-сервер. Каждой из шести страниц соответствуют три ширины: **320, 768 и 1280 px**. Изображения сохранены в формате JPEG; они предназначены как доказательство интерфейсного состояния в рабочей курсовой и не являются сторонними фотографиями.

- **Главная:** [320](index-320.jpg), [768](index-768.jpg), [1280](index-1280.jpg)
- **Каталог стран:** [320](countries-320.jpg), [768](countries-768.jpg), [1280](countries-1280.jpg)
- **Карточка Финляндии:** [320](country-finland-320.jpg), [768](country-finland-768.jpg), [1280](country-finland-1280.jpg)
- **Сравнение стран:** [320](compare-320.jpg), [768](compare-768.jpg), [1280](compare-1280.jpg)
- **Факторы и калькулятор:** [320](factors-320.jpg), [768](factors-768.jpg), [1280](factors-1280.jpg)
- **Источники:** [320](about-320.jpg), [768](about-768.jpg), [1280](about-1280.jpg)

[Машинный протокол снимков](manifest.json) содержит дату съёмки, название страницы, HTTP-код, viewport, scrollWidth и массив необработанных ошибок JavaScript. В указанном прогоне все 18 страниц вернули HTTP 200, а горизонтального переполнения и JavaScript-исключений не обнаружено. Эти тесты не заменяют визуальный осмотр и проверки Firefox и Safari.

Не путать с требованиями анализа сайтов-аналогов: скриншоты сторонних ресурсов должны быть подготовлены отдельно и подписаны реальными адресами источников.
