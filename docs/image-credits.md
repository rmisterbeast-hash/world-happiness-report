# Авторские фотографии, лицензии и преобразования

Для оформления информационного ресурса использованы три фотографии из Wikimedia Commons. Лицензионные страницы проверены 21 октября 2026 г. Оригиналы доступны по приведённым ссылкам. В проекте используются уменьшенные и перекодированные копии в WebP (640 и 1200 px). Каждая такая копия распространяется по **CC BY-SA 4.0**; ссылка на лицензию: https://creativecommons.org/licenses/by-sa/4.0/ . Название авторства и ссылки должны сохраняться при любом дальнейшем распространении изображений. Лицензия на фотографии не заменяет лицензию на код проекта.

- **city-helsinki** — автор: JIP; оригинал: https://commons.wikimedia.org/wiki/File:Skyline_of_Helsinki_seen_from_Hotel_Torni.jpg; лицензия: CC BY-SA 4.0; преобразования: масштабирование и перекодирование JPEG → WebP, без существенной ретуши. Файлы `images/city-helsinki-640.webp` и `images/city-helsinki-1200.webp`.
- **city-tokyo** — автор: Maksym Kozlenko; оригинал: https://commons.wikimedia.org/wiki/File:Tokyo_Street.jpg; лицензия: CC BY-SA 4.0; преобразования: масштабирование и перекодирование JPEG → WebP, без существенной ретуши. Файлы `images/city-tokyo-640.webp` и `images/city-tokyo-1200.webp`.
- **city-paris** — автор: DiscoA340; оригинал: https://commons.wikimedia.org/wiki/File:City_Street_in_Paris,_France_2.jpg; лицензия: CC BY-SA 4.0; преобразования: масштабирование и перекодирование JPEG → WebP, без существенной ретуши. Файлы `images/city-paris-640.webp` и `images/city-paris-1200.webp`.

При создании сборки используется скрипт `scripts/generate_photos.py`. Исходные оригиналы JPEG не включены в репозиторий, чтобы избежать лишнего веса.
