# Анализ сайтов-аналогов: фактические скриншоты

Подготовка: реальное отображение независимых сайтов через Chromium в GitHub Actions. Скриншоты НЕ являются стилизованной имитацией. Для каждого сайта предусмотрены две страницы — вводная и внутренняя. Проверяются HTTP 200, заголовок, минимальный объём реального текста, отсутствие выраженной CAPTCHA или блокировки. Если сайт блокирует автоматический доступ, вместо выдуманного изображения остаётся отметка в manifest.json.

- World Happiness Report: https://worldhappiness.report/ed/2024/ и глава об оценках разных возрастов.
- Our World in Data: https://ourworldindata.org/happiness-and-life-satisfaction и график Cantril Ladder.
- OECD Better Life Index: https://www.oecd.org/en/data/tools/well-being-data-monitor/better-life-index.html и Current Well-being dashboard.

Снимки фиксируют состояние сайтов на дату запуска и используются только для критического сравнения в учебной пояснительной записке. Авторские права принадлежат правообладателям сайтов. Адреса, дата, результаты и ошибки фиксируются в manifest.json.
