# Атлас благополучия — World Happiness Report 2024

Учебный многостраничный веб-сайт по дисциплине «WEB-дизайн». Тема: **«Разработка информационного веб-сайта об уровне счастья и благополучия в странах мира»**.

**Студент:** Канивец Егор, группа 301. **Университет:** ПГУ им. Т. Г. Шевченко. **Преподаватель:** к.т.н., доцент Саломатина Е. В.

## Что реализовано

- Лицензированные фотографии Хельсинки, Токио и Парижа (6 локальных WebP, CC BY-SA 4.0, атрибуция авторов и оригиналов на сайте и в [реестре изображений](docs/image-credits.md)); на главной сохранены авторские иллюстрации и добавлена фотогалерея. Остальные страницы используют фотографии в первом экране.

- Интерактивная карта мира на главной странице: реальные оценки World Happiness Report 2024 при наведении, выделение стран, поиск, карточки, работа с касанием и клавиатурой. Все 143 страны отчёта показаны (137 контуров и 6 точечных маркеров). Географические пути подготовлены из открытых границ Natural Earth и локально сохранены в `data/world-map.json`; [источники и методика геокодирования](./data/world-map-README.md).

- Шесть HTML5-страниц: `index.html`, `countries.html`, `country.html?name=Finland`, `compare.html`, `factors.html`, `about.html`.
- Первый экран с лидером WHR 2024 из JSON; опубликованный рейтинг 2024 и пересчитанные по годовому ряду исторические рейтинги с предупреждением при неполном охвате (менее 50 стран), поиск/регион/сортировка/пагинация.
- Годовые графики, сравнение до трёх стран, диаграмма рассеяния на Chart.js.
- Клиентский калькулятор с весами шести факторов от 0 до 5.
- Избранное до пяти стран в `localStorage`; модальные окна, клавиатурная навигация, адаптивные компоненты.
- Статическая загрузка JSON по `fetch()`, без бэкенда.

Картографическое уточнение: **Крым отображается в составе Украины** в соответствии с международно признанными границами (резолюция Генеральной Ассамблеи ООН 68/262). В SVG-слое контур Крыма удалён из геометрии России и объединён с геометрией Украины. В интерактивной подсказке показывается оценка Украины из World Happiness Report 2024, а не несуществующий самостоятельный индекс Крыма. Воспроизвести преобразование можно скриптом `node scripts/assign_crimea_ukraine.mjs`.

## Источники данных

Назначенный преподавателем набор: [World Happiness Report 2024 — Kaggle](https://www.kaggle.com/datasets/jainaru/world-happiness-report-2024-yearly-updated). Исходная методология: [World Happiness Report 2024](https://worldhappiness.report/ed/2024/).

Прямая загрузка Kaggle в рабочей среде пока не была подтверждена. Срез 2024 (143 страны) и годовые записи 2005–2023 (2363 наблюдения) обработаны из [публичных зеркал двух CSV](./data/README.md). **Сверка с оригинальным архивом Kaggle остаётся обязательным этапом.**

**Не смешивать:** 2024 — опубликованный многолетний рейтинг; 2005–2023 — годовые наблюдения, по которым пересчитаны исторические места. Шесть факторов среза 2024 — **вклады** в оценку, а не прямые годовые показатели. Пропуски хранятся как `null`.

## Воспроизводимость обработки

[Открыть совместимый ноутбук Google Colab](https://colab.research.google.com/github/rmisterbeast-hash/world-happiness-report/blob/main/notebooks/preprocess_whr2024.ipynb) — программа подготовки трёх JSON из двух исходных CSV. Статус фактического запуска в Colab пока **не подтверждён**.

- `data/countries.json` — русские названия, регионы, рейтинг 2024 и шесть вкладов.
- `data/happiness.json` — годовые наблюдения 2005–2023, без подстановки нуля в пропуски.
- `data/ranking.json` — отдельные наборы опубликованного и пересчитанных рейтингов.

## Технологии и структура

HTML5, CSS3, JavaScript ES Modules, Chart.js 4, JSON, fetch(), localStorage, CSS Grid, Flexbox, CSS-переменные, Nested БЭМ. Верстка mobile-first. Без Bootstrap и серверной части.

- `blocks/` — CSS-блоки, их `elements/` и `modifiers/`.
- `js/` — модули работы с данными, UI и страницами.
- `images/` — авторские SVG и реально сгенерированные WebP-версии 640/1200 px. В HTML настроены `srcset`, `alt` и `loading`. Дополнительные фотографии городов и людей ещё предстоит подобрать и атрибутировать.
- `notebooks/` — исходник предобработки для Google Colab.

## Запуск и публикация

Файлы должны открываться через HTTP(S), поскольку `fetch()` обычно блокируется при запуске `file://`. Для локальной разработки: `python -m http.server 8000`, затем http://localhost:8000.

**Опубликованный сайт (GitHub Pages):** https://rmisterbeast-hash.github.io/world-happiness-report/ . Источник: **GitHub Actions**; 20.10.2026 автоматическая публикация подтверждена успешным выполнением [Deploy website to GitHub Pages](https://github.com/rmisterbeast-hash/world-happiness-report/actions/runs/39456819562) (повторная попытка №2). После изменений в `main` актуальная версия сайта развёртывается автоматически. Открытие страницы из пользовательского браузера необходимо подтвердить отдельно.
