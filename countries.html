Место в рейтинге не равно абсолютной характеристике страны

Ранжирование упорядочивает государства по величине среднего показателя. Даже соседние позиции могут различаться совсем незначительно, а значения опроса сопровождаются статистической неопределённостью. Поэтому корректнее рассматривать место вместе с числовой оценкой, доверительным интервалом и периодом сбора данных.

Каталог показывает срез, использованный в отчёте World Happiness Report 2024. Он не измеряет качество образования, безопасность, стоимость жизни и другие показатели в единой комплексной шкале. Для изучения того, как средние оценки менялись со временем, предусмотрена отдельная карточка каждой страны.

Поиск выполняется по названиям стран без учёта регистра. При изменении фильтра просмотр возвращается к первой странице. Для стран без доступного показателя на сайте предусмотрена подпись «нет данных».
