# Interactive world map / Источники географических границ

Карта на главной странице использует геометрию [Natural Earth, ne_110m_admin_0_countries](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson). Лицензия: [общественное достояние / Public Domain](https://www.naturalearthdata.com/about/terms-of-use/).

Исходные координаты были преобразованы в SVG-пути (прямоугольная проекция, ширина 1000), после чего сохранены в локальном `world-map.json`. Данные о странах в его объектах используются **только для соединения географии с названиями**. Отчётные баллы в географическом файле намеренно отсутствуют: приложение берёт оценки жизни и места из `countries.json` (World Happiness Report 2024). Это предотвращает появление двух противоречащих друг другу источников данных.

В географическом слое Natural Earth масштаба 1:110 000 000 содержатся контуры для 137 из 143 стран рейтинга. Для ещё шести небольших стран и территорий — Бахрейна, Гонконга, Коморских островов, Мальты, Маврикия и Сингапура — использованы точечные маркеры. Их координаты получены по географическим рамкам проекта [country-json](https://github.com/samayo/country-json/blob/master/src/country-by-geo-coordinates.json); для Маврикия маркер установлен на главном острове, поскольку географическая рамка включает удалённые острова.

**Контроль:** 137 сопоставленных контуров + 6 точек = 143 страны рейтинга. Территории без значения рейтинга серые; для них число не придумывается.

**Ограничения:** границы и названия приводятся в соответствии с выбранным картографическим источником и служат только для учебной визуализации; показ границ не является выражением политической позиции. В данном масштабе география схематична, небольшие территории выделяются символами. Карта 2024 года — снимок опубликованного World Happiness Report 2024 (многолетний период 2021–2023), не онлайн-оценка «на сегодня».

## Крым и международно признанные границы Украины

В поставляемой по умолчанию версии Natural Earth 1:110m используется схема фактического контроля территорий. В рамках этого учебного проекта Крым отображается **в составе Украины**, в соответствии с международно признанными границами Украины и [резолюцией Генеральной Ассамблеи ООН 68/262](https://digitallibrary.un.org/record/767883/files/A_RES_68_262-EN.pdf). Для этого из составного SVG-пути России удалён отдельный полигон полуострова и добавлен в SVG-путь Украины. Перекрытия двух стран отсутствуют. Коррекция воспроизводится командой `node scripts/assign_crimea_ukraine.mjs` (повторный запуск безопасен).

При наведении, выборе или использовании клавиатуры участок Крыма относится к интерактивной фигуре Украины. Отображается показатель **Украины в целом** из `countries.json`. Отдельный индекс для Крыма не создаётся, поскольку в наборе World Happiness Report 2024 отсутствует отдельная запись для полуострова. Данная корректировка относится только к геометрическому отображению и не меняет исходные статистические показатели.
